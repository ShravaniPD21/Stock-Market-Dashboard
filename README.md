# 📈 Marketly – Stock Market Dashboard

Marketly is a modern, responsive stock market dashboard designed to provide users with a clean and intuitive interface for tracking stock market performance, monitoring investments, and viewing portfolio analytics.

Built using **HTML, CSS, and JavaScript**, the dashboard features a dark-themed trading interface with interactive charts, market indices, portfolio statistics, stock watchlists, and recent transactions.

## ✨ Features

- **Market Overview:** Displays key Indian market indices, including NIFTY 50, SENSEX, and BANK NIFTY.
- **Portfolio Summary:** Shows total portfolio value, total investment, overall returns, and daily profit/loss.
- **Interactive Performance Chart:** Visualizes portfolio performance with selectable time ranges (1D, 1W, 1M, 3M, 1Y, ALL).
- **Asset Allocation:** Displays portfolio distribution across equity, mutual funds, ETFs, and cash.
- **Stock Watchlist:** Tracks stock prices, percentage changes, market capitalization, and volume.
- **Stock Search:** Allows users to search and filter stocks in their watchlist.
- **Top Movers:** Highlights stocks with significant positive and negative price movements.
- **Recent Transactions:** Displays recent buy and sell transactions.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screen sizes.

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Google Chrome, Firefox, Edge, etc.).
- Visual Studio Code (recommended).
- Live Server extension (optional).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/your-username/marketly.git
```

**2. Navigate to the project directory**

```bash
cd marketly
```

**3. Run the application**

Open `marketly-stock-dashboard.html` directly in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

No additional package installation or build process is required.

## 📊 Dashboard Modules

1. **Market Indices:** Quick overview of major Indian stock market indices.

## ⚠️ Data Disclaimer

This project currently uses sample stock market data for demonstration purposes.

It does not fetch real-time stock prices, execute trades, or connect to a brokerage platform.

Chart.js and Google Fonts are loaded through external CDNs, so an internet connection is required for those resources.
